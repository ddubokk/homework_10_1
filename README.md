# Проект домашнего задания 10.1
# Виджет банковских операций (продолжение предыдущих заданий 9.1 и 9.2)

Учебный Python-проект для обработки и безопасного отображения банковских данных. Программа умеет маскировать номера карт и счетов, форматировать даты, а также фильтровать и сортировать списки банковских операций.

## Технологии
- **Python 3.13**
- **Poetry** — управление зависимостями и виртуальным окружением
- **Flake8**, **Mypy**, **Black**, **Isort** — проверка стиля кода, форматирование и статическая типизация


## Установка и запуск

1. Скопируй репозиторий к себе на компьютер:
```bash
git clone git@github.com:ddubokk/homework_10_1.git
cd homework_10_1
```

2. Установи зависимости через Poetry:
```bash
poetry install
```

3. Запусти скрипты для проверки работы функций:
```bash
poetry run python -m src.main
poetry run python -m src.main1
```

## Описание модулей

1. Маскировка карт и счетов (`src/masks.py`).

2. Форматирование дат и данных карты/счёта (`src/widget.py`).

3. Фильтрация и сортировка операций (`src/processing.py`).
